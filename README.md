# AlgoForge

AlgoForge is a private, local, paper-only quantitative research workstation. It builds immutable research runs, deterministic verdicts, ordinary risk analysis, versioned prop-firm simulations, bounded research-agent projections, and guarded application-maintenance evidence.

Current state: implementation in ten Git-tracked waves. All bundled market and strategy output is sample data and uncalibrated. No live-order, account-signup, payment, KYC, or production-broker capability exists.

## Development prerequisites

- Windows with PowerShell
- Python 3.13 via `uv`
- Node.js 22–24 and npm
- Git and GitHub CLI

Commands are added and verified as each wave lands. Architecture and the executable plan are in `docs/superpowers/`.
