# Quant workstation overhaul implementation plan

**Goal:** Reframe AlgoForge as a research-first desktop control room while preserving the current engine and evidence contracts.

**Architecture:** Keep every existing backend workflow. Build a grouped, hash-routed application shell and add small read-only projections for runs, memory and data health. Preserve lazy boundaries and TanStack Query caching. Agent controls remain available in a compact operations view.

**Design:** Warm graphite, copper selection, semantic validation colours, IBM Plex, dense records, restrained transition motion, no decorative orbital animation.

## Work items

1. Record product context, baseline audit, information architecture and acceptance gates.
2. Replace the top-tab shell with collapsible grouped navigation, a compact context bar, global status strip and event drawer.
3. Add a `Ctrl+K` palette for routes and live strategy records.
4. Add Runs, Research Memory, Lineage and Data Health as first-class read-only views.
5. Rebuild Overview around mission, engine, research-loop, candidates and observed coverage.
6. Rebuild Agent Command as a compact role table and inspector while retaining dispatch, worker and research controls.
7. Apply the workstation token and responsive layer without changing API semantics.
8. Update route and interaction tests; run the design detector, Vitest, production build, Python lint/type/tests and browser smoke.
9. Update vault session/evidence records, commit, push `main`, fetch and compare local/remote heads.
