# AlgoForge agent command and research upgrade

Authorized scope: repository audit, UI overhaul, eight search workers, observable and
controllable specialist agents, internet research, quantitative experiments, latency
improvements, and local verification. Preserve the existing paper-only architecture.

The implementation keeps React, FastAPI, the deterministic judge and evidence ledger.
Eight specialist roles are Research scout, Hypothesis analyst, Strategy engineer,
Validation analyst, Risk officer, Post-mortem analyst, Bulk worker and Console chat.
Their operations expose current task, tool, duration, sources, result summaries and
errors. Summaries are operational outputs, not private model chain of thought.
An Agent Command page combines a selectable animated network, worker lanes, role
controls, activity and a searchable research library. Existing pages receive shared
surface, spacing, typography and motion improvements with reduced-motion support.

Research uses fixed scholarly APIs with bounded requests and persistent provenance.
Documents and supplied transcripts are evidence, never operating instructions.
Curated papers have explicit replication gaps. New runnable statistical templates
are adaptations, not claimed replications. Options positioning and multi-asset
residual strategies remain capability-gated until their required data exist.

Models produce structured, range-checked experiment proposals against executable
templates. They can adjust bounded parameters and hypotheses, with citations, but
cannot modify verdicts, see holdout data or execute fetched Python. Deterministic
research still operates if credentials are unavailable; the UI states which mode ran.
Eight compute workers use varied search policies, durable attempts and development
scores for neighbourhood exploration. Failed validation does not train selection.

Audit repairs cover lifecycle races, in-flight pruning, activity synchronization,
parameter persistence, stable strategy IDs, dataset-aware experiment memory, and
truthful API/engine status. Verification: backend suite, lint/type checking, frontend
tests/build, browser core flows at PC laptop/desktop/ultrawide sizes, live scholarly fetch and local
paper-only smoke runs. Findings and remaining limits are recorded in the trading vault.
